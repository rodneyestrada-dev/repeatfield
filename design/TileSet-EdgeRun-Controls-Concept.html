What changed

Removed: Phase slider and Reverse direction. Neither describes the visual result; both only modify turn parity.

Kept: the automatic side-aware edge layout, now with an understandable primary operation.

Acceptance criteria for implementation: Universal turn changes all Edge placements by one selected quarter turn; By side exposes independent Top / Right / Bottom / Left turns; switching modes preserves each mode’s values; alternate rhythm is off by default; A/B start selection replaces numeric Phase; no control is labelled “reverse” unless it truly reverses placement order; Edge preview makes affected tiles visible before export.
